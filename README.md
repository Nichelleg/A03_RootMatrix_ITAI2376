# A03 Neural Network Zoo
### Team Root Matrix: Cesar Noriega, Mary Ann Mastri, Luiz Paludo, Nichelle Graf
## Project Overview

The Neural Network Zoo project explores the structure, behavior, and real-world applications of a selected neural network architecture through research, visual explanation, and analogy.

Our team selected the **Graph Neural Network (GNN)** and paired it with the **wolf spider** as a creative metaphor for connectivity, information flow, environmental awareness, and relational structure.

Rather than using the animal theme as a simple mascot, the project uses animal characteristics as an analogy for how a neural network is structured and how it processes information. This helps make abstract deep learning concepts more intuitive, memorable, and easier to communicate.

---

## Selected Neural Network

### Graph Neural Network (GNN)

Graph Neural Networks are designed for graph-structured data, where information is represented through:

- **Nodes** — entities or individual data points
- **Edges** — relationships or connections between nodes
- **Message passing** — the exchange and aggregation of information between connected nodes
- **Graph structure** — the larger network of relationships being analyzed

GNNs are especially useful when the relationships between data points are as important as the data points themselves.

## Neural Network Zoo Animal

### Wolf Spider

The wolf spider was selected as the animal metaphor for the GNN because it provides a visual and conceptual way to represent:

- Sensory awareness and individual processing
- Information received from the surrounding environment
- Connections and pathways between related information
- Interaction between individual features and the larger relational structure

The metaphor is intended to make the core ideas behind GNNs easier to understand and explain.

## Project Objectives

This project:

- Introduces the basic concepts of neural networks and deep learning
- Explains how artificial neurons are organized into layers and networks
- Examines the structure and operation of Graph Neural Networks
- Explains how message passing works in a GNN
- Identifies real-world applications of GNNs
- Uses an animal analogy to illustrate important GNN characteristics
- Connects technical concepts with visual storytelling
- Reflects on how GNNs differ from other neural network architectures

## Real-World Applications

Graph Neural Networks are used in areas where relationships and connections play an important role, including:

- Fraud detection
- Recommendation systems
- Social network analysis
- Molecular and biological modeling
- Traffic and route optimization
